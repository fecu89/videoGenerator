# 편집·쇼츠·전달 검토 기록

기준: [편집·쇼츠·전달 검토](../../docs/editorial-release-checks.md).
이 양식을 run에 복사한 뒤 기준 경로를 프로젝트 경로로 적는다.
에이전트 검토 기록이며 자동 CLI 게이트나 사용자 승인 파일을 대신하지 않는다.

- 실행/검토 시각/검토자:
- 사용한 script·translations·upload-overrides 경로와 SHA-256(없는 파일은 없음):
- 사용한 계획·원본 음성·완성 MP4/자막 경로와 SHA-256:
- 이번 사용자 요청과 기존 승인 범위:
- 상태: 미검토

판정은 `통과 / 수정 필요 / 미검토 / 해당 없음`이며 실제 근거를 붙인다.
