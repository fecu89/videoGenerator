# 쇼츠의 화면 배치

확인일: 2026-10-12. 파일은 **1080×1920, 9:16**으로 만든다. 기본 배치는 사용자가
확정한 `runs/20261010-geomagnetic-dynamo/shorts`의 구도를 그대로 따른다.

| 요소 | 상자 (x, y, 너비, 높이) | 글자 |
| --- | --- | --- |
| 제목 | 30, 300, 1020, 130 | 최대 92px, 한 줄에 맞게 축소 |
| 그림 | 0, 500, 1080, 724 | 가로 영상의 84% 폭을 전폭으로 (`cover`) |
| 자막 | 70, 1279, 940, 280 | 한국어·중국어 70px, 일본어 66px, 그 외 64px |

위 290px과 아래 360px은 배경(흐린 본편)만 보인다. Google의 광고용 안전영역
수치는 적용하지 않는다. 실제 Shorts 앱의 UI 가림은 실기기에서 확인한다.

## 제작 계약

- `shorts-safe-layout.json`은 공통 배치 값이다. 실행 폴더의 `shorts-layout.json`으로
  명시적으로 덮어쓸 수 있다. 기존 `run-settings.json`, 대본·음성 승인 해시는 바꾸지 않는다.
- 제목·그림·자막 상자는 `safe_area` 안에 있고 서로 겹치지 않는다. 그림은 `cover`
  (전폭, 좌우 8%씩 잘림) 또는 `contain`(전체를 넣고 축소)으로 맞추며 찌그러뜨리지 않는다.
  잘린 좌우에 핵심 대상이 있으면 세로 구도를 다시 설계한다.
- 줄바꿈은 글자 수 상수로 자르지 않는다. 스타일 여백을 상자(외곽선만큼 안쪽)로 두어
  libass가 띄어쓰기 언어를 상자 안에서 줄바꿈하고, 일본어·중국어만 상자 폭을 글자 크기로
  나눈 글자 수로 미리 자른다. 제목은 상자 폭에 맞춰 한 줄 크기를 줄인다.
- 공통 쇼츠 명령은 실제 libass로 **모든 제목·자막 큐**를 그려 각 글자 상자를 검사한다.
  초과 시 인코딩을 중단한다. 띄어쓰기 없는 긴 토큰(주소 등)은 libass가 자르지 못해
  이 검사에서 멈추며, 그때는 자막 큐를 고쳐 다시 만든다. 검은 바탕에서 측정하므로
  1px 검은 그림자는 측정에 들어가지 않는다. 글자 상자 검사는 객체의 의미나 실제 UI
  가림을 판별하지 못한다.
- run 전용 쇼츠 제작기도 같은 배치와 `inspect_ass_bounds`를 사용한다.

## 인코딩 후 검토

1. 각 언어 MP4에서 시작·모든 새 접합부의 전중후·끝·가장 긴 자막을 추출한다.
   원본 ASS 위치만 읽고 통과시키지 않는다.
2. 제목, 실제 번인 자막, 바늘 끝·핵심 경로가 잘리지 않고 구별되는지 본다.
3. 실기기가 있으면 iOS/Android의 실제 Shorts 재생 화면에서 기본 UI와 기본 CC 상태를
   확인한다. 없으면 `실기기 미확인`으로 기록한다.
4. `release-review.md`에 MP4·배치·ASS 해시, 프레임 시각, 실기기 검사 여부를 기록한다.
   음성·자막 싱크 검토도 기존 기준대로 유지한다.

기존 영상의 배치 수정은 후처리 범위에서 해결하고 본편·확정 음성을 재사용한다.
새 사용자 승인 단계를 추가하지 않으며 외부 업로드는 실제 완성본 검토 이후 실행한다.
