## 현재 구조

- schema-v4와 프로젝트 설정은 VoxCPM2만 허용한다. 엔진 선택, CustomVoice 화자·전역 프롬프트·샘플링 인자와 MLX 합성 모듈을 제거했다.
- `voice_audio.py`는 DSP, 문장 여백, FFmpeg 인코딩, 원자적 게시를 담당한다. `voxcpm_voice.py`는 네이티브 모델과 참조 특징 고정을 담당한다.
- `directed` 모드와 `acting_style`은 같은 참조 음색을 사용하면서 문장별
  감정·강도를 적용한다. `script_only`에서 지시가 빠지면 합성 전에 중단한다.
  기존 `locked` 결과와 비활성 기본값의 승인 해시는 유지한다. [대본 연기](voice-acting.md)를 따른다.
- 과거 실행은 `ArchivedHarnessSettings`와 `archived_voice_settings.py`로 읽기만 지원한다. 과거 승인 해시를 보존한다. 구형 설정으로 합성을 요청하면 명시적 새로고침을 안내하고 중단한다.
- 기본 속도는 `speed_mode: manual`, `speaking_rate: 1.0`으로 Vox 원음의 발화 속도를 유지한다. `target_syllables_per_second: 5.2`는 자동 보정을 선택한 경우에만 속도에 영향을 준다. 문장 여백·긴 무음 정리·음량 균일화는 별도로 유지한다.
- 자동 속도는 실제 발화 길이/목표 길이로 0.8~1.25배를 적용한다. 수동 배율은 별도 모드이며 두 값을 겹쳐 적용하지 않는다. 감속할 때 내부 무음도 미리 보정해 쉼 상한이 늘어나지 않게 한다.
- 보고서에 보정 전후 발화 시간, 적용 배율과 `target_reached`를 기록한다. 한계 때문에 목표를 못 맞추면 이를 숨기지 않는다.
- 설정 화면은 목소리, 말하기, 음량, 모델, 영상 구성, 렌더링, 품질 검사로 구성했다. 참조 전사문은 여러 줄 입력, 모델 세부 값은 고급 설정으로 제공한다.
- 문장마다 사용하지 않는 장치 캐시를 비우고, CLI 작업 종료·실패 시 모델과
  고정 참조 캐시를 해제한다. 여러 번 호출하는 합성기는 `with` 또는 `close()`로
  수명을 관리한다. [모델별 메모리 수명](architecture.md#모델별-메모리-수명)을 따른다.

## 검증

- 모델 메모리 수명 추가 검증: 관련 테스트 **63 통과**. 장치별 캐시 정리,
  모델 재사용, 종료·실패 시 해제, 외부 주입 모델의 소유권을 확인했다.
- 전체 Python 테스트: **588 통과, 16 건너뜀**. 삭제된 엔진 전용 테스트는 제거하고 DSP·원자적 게시 검사와 Vox 테스트로 대체했다.
- 실제 FFmpeg: 빠른/느린 원음이 같은 목표 길이에 도달하는지, 자동 모드에 수동 배율이 겹치지 않는지, 문장 양끝 여백과 감속 후 내부 무음 상한이 유지되는지 확인했다.
- 실제 Chromium: 모드별 항목 표시, 필수 참조·전사문 누락 차단, 저장·재열기, 1440/390px 가로 넘침 검사를 통과했다.
- 실제 VoxCPM2/MPS: 별도의 확인용 문장으로 3.96초 MP3 생성. 적용 배율 0.954626, 보정 발화 2.884615초, 목표 도달. 독립 Whisper 전사는 입력 문장과 일치했다. 직접 청취나 완성 영상 재생성을 수행한 것으로 간주하지 않는다.
- 확인 산출물: `tmp/vox-v4-smoke/`, UI 이미지 `tmp/vox-studio-ui*.png`.

사용법과 전체 설정 항목은 [settings.md](../../settings.md)를 따른다.
