# 대본 연기와 목소리 일관성

대본의 문장별 연기 작성·표시는 현재 실행의 effective settings를 따른다.
전체 말투와 문장별 감정을 구분하며, 나레이션 문자열에는 연기 지시를 섞지 않는다.

| 현재 설정 | 새 대본의 `sentence_delivery` | 대화·`story-review.md` |
|---|---|---|
| `voice.emotion_mode=off` | 생략 또는 `[]` | 감정·강도 표기 없이 대사만 표시 |
| `voice.emotion_mode=script_only` | 모든 문장의 감정·강도 작성 | 문장별 한국어 연기 지시 표시 |

off에서는 “검토용”이라는
이유로 연기 지시를 붙이거나 `neutral` 지시를 채우지 않는다. 선택한 전체 말투는
그대로 유지하며, 밝은 말투나 질문·해답이라는 문장 기능으로 감정을 자동 부여하지 않는다.
과거 승인 대본의 메타데이터는 설정 조회만으로 삭제하지 않는다. 대본 재작성은
현재 설정을 따르고, 과거 실행의 `run-settings.json`과 승인본은 보존한다.

연기 모드의 `sentence_delivery` 문장 번호는 하네스의
`split_narration_sentences` 기준이며 1부터 시작한다.

## 설정

- `instructions_file`: Sohee의 전체 톤 프리셋을 선택한다. 문장별 연기를 꺼도
  선택한 전체 톤은 유지한다.
- `emotion_mode: script_only`: 대본에 명시된 각 문장의 감정과 강도를 적용한다.
  한 문장이라도 지시가 누락되면 모델 로딩 전에 실패한다. 중복·범위 초과 문장
  번호는 대본 스키마가 거부한다. `neutral`도 명시적인 연기 선택이다.
- `emotion_mode: off`: 문장별 변화만 끈다. 새 대본의 연기 지시 작성·표시도
  생략한다. 기본 말투는 별도로 적용된다.
속도와 음량 설정은 별도로 유지한다. 연기 강도를 배속이나 볼륨으로 대신하지 않는다.

## 문장별 연기 대본

다음 예시와 감정·강도 표기는 문장별 연기가 활성화된 경우에만 사용한다.

```json
"sentence_delivery": [
  {"sentence_index": 1, "emotion": "bright", "intensity": "moderate"},
  {"sentence_index": 2, "emotion": "curious", "intensity": "moderate"},
  {"sentence_index": 3, "emotion": "confident", "intensity": "subtle"}
]
```

| 감정 | 연기 방향 |
|---|---|
| bright | 밝게 미소 짓는 도입, 친근한 환기 |
| curious | 호기심, 질문 끝을 가볍게 올리기 |
| confident | 해답의 핵심을 자신 있게 강조 |
| surprised | 발견 순간의 짧은 놀라움, 고함은 피하기 |
| gentle | 부드러운 정리와 안심시키는 설명 |
| neutral | 차분하고 고른 정보 전달 |

강도는 `subtle`(약하게), `moderate`(분명하게)다. 문장 기능을 보고 사람이
선택한다. 문장부호만 보고 감정을 자동 부여하지 않는다. 승인용 대본에는
각 문장 옆에 `[호기심 · 중간]`처럼 지시를 읽기 쉽게 보여준다.

## 제작 순서와 검토

### 종류별 쉼

프로젝트 설정과 템포 프리셋 v2는 `voice.pause_mode: typed`를 사용한다.
쉼표는 80~150ms(기본 120), 의미 구분은 150~250ms(200), 강조는
300~400ms(350), 문장 사이는 400~600ms(500)로 설정한다. 쉼표는 자동으로
찾되 숫자 안의 쉼표는 제외한다. 의미 구분과 강조는 다음처럼 본문과 분리한다.

```json
{
  "narration": "빛은, 안개를 통과하며 점점 약해집니다.",
  "sentence_pauses": [
    {"sentence_index": 1, "after": "통과하며", "kind": "semantic"},
    {"sentence_index": 1, "after": "점점", "kind": "emphasis"}
  ]
}
```

`after`는 해당 문장에서 한 번만 나타나는 구절이어야 하며 단어 중간이나
문장 끝을 지정하면 안 된다. 같은 위치의 쉼표보다 명시한 쉼이 우선한다.
연기 설정이 꺼져 있어도 쉼은 사용할 수 있다. 대본 검토 웹에 지정 위치를
표시하고, 수정 의견으로 위치와 종류를 바꿀 수 있다. TTS와 자막에는 이
메타데이터를 읽힐 문자열로 넣지 않는다.

Qwen·Kokoro는 지정 경계에서 구절을 합성하고, 속도 보정 뒤에 정해진 무음을
넣는다. 임의의 긴 멈춤을 줄이는 `max_internal_pause_ms`는 구절 내부에만
적용한다. 문장 앞뒤 여백을 별도로 더하지 않으므로 문장 간격은 설정값
전체다. 음성 보고서는 문장 단위와 실제 출력 길이, `pause_events`를 기록한다.
짧은 구절을 따로 합성하면서 억양이 달라질 수 있으므로 새 음성은 청취한다.

기존 실행에서 이 필드가 없으면 `legacy`로 해석하며 설정 해시와 기존 여백을
보존한다. 기존 음성은 자동 재생성하지 않는다. 번역문에는 한국어의 위치
정보를 복사하지 않으며, 현재 번역 음성은 문장부호에 따른 쉼을 자동 적용한다.

### 검토 순서

1. 현재 음성 설정을 확인하고 대본을 작성한다. off이면
   연기 지시를 작성·표시하지 않는다. script_only이면 질문 사슬과 함께 모든
   문장의 연기를 작성한다.
2. 현재 설정에 맞는 대본을 검토하고 승인받는다. 연기만 수정하라는 요청에서는
   승인된 나레이션을 그대로 보존하고 요청 범위의 연기 지시를 수정한다.
3. 도입·질문·해답이 포함된 짧은 샘플을 생성해 기존 음성과 비교한다.
4. 음색 변화, 과장된 강약, 지시문을 소리 내어 읽는 현상, 발음 누락을 확인한다.
   자동 음량 검사는 청취 검토를 대신하지 않는다.
5. 검토한 설정으로 전체 음성을 생성한다. 실패하거나 미검토된 음성을
   완성 영상용으로 승인했다고 처리하지 않는다.

`voice-generation-report.json`은 실제 전달한 `instruction`과 해시, 모델·화자·
토큰·속도 정보를 기록한다. 샘플은 별도 폴더에 저장하고 기존 완성본의 설정·
오디오·승인 해시를 바꾸지 않는다.

현재 schema-v5와 과거 schema-v4 Qwen 실행은 문장별 지시 누락을 차단한다.
과거 schema-v3 Qwen 실행은 원래의 선택적 지시 적용 방식을 유지한다.
